# About MONAD

MONAD is a local-first knowledge system by seclib. The goal is to give users a practical, self-hosted environment for offline resources, local AI assistance, maps, documents, and personal knowledge workflows.

MONAD can run on modest local hardware, but the AI tools benefit from a capable CPU, enough RAM, and a GPU-backed device when available.

Since its initial release, MONAD has grown to include built-in AI chat with a Knowledge Base for document-aware responses, a System Benchmark with a community leaderboard, curated content collections with tiered options, and an Easy Setup Wizard to get new users up and running quickly.

MONAD is open source, released under the [MIT License](https://github.com/seclib/monad/blob/main/LICENSE).
